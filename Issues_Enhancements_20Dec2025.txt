Issues/Enhancements (December 20, 2025):
I don’t see an option to add blocks to a Columns layout or section container.
How will adding blocks to different layouts work? Will we be able to add blocks to each column in a columns layout? Will we be able to add columns layout within a column in a columns layout? And in the columns layout, when we are choosing 2 or 3 columns or how many ever, by default there is spacing between the columns. There should be an option to override this if needed by the admin, so, for example, we choose a 2 column layout with no spacing between them and on one column we fill an image and in the other column we stack text blocks or whatever. And, not sure if it is already there, we should also be able to adjust the padding within every column in a columns layout. Overall, we need a sophisticated, flexible system.
