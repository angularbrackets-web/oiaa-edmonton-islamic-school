# Create Content Type Command

Create a new Payload CMS content type.

Use the CMS Admin Specialist Agent to create a new content type:

{{content_type_name}}

Requirements:
- Bilingual support (English + Arabic)
- Proper field validation
- Access control (admin/editor roles)
- Media upload support if needed
- SEO fields
- Timestamps

The agent should design the complete schema, implement it, and document the content model.
