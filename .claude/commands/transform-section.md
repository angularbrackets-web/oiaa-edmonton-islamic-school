# Transform Section Command

Transform a website section using the Section Transformer Agent.

Use the Section Transformer Agent to transform the specified section:

{{section_name}}

The agent will:
1. Analyze the current section state
2. Map Hero section patterns to the new context
3. Create a comprehensive transformation plan
4. Coordinate specialized agents (Frontend, Backend, Design, CMS)
5. Execute the transformation
6. Create pattern documentation

Please follow the mandatory workflow and create {{section_name}}_SECTION_PATTERNS.md when complete.
